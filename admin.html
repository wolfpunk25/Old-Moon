Log in

Paste a GitHub personal access token with read/write access to this repo only. Create one at github.com/settings/personal-access-tokens/new — under "Repository access" choose "Old-Moon" only, and under "Permissions" grant Contents: Read and write.

You only need to do this once per device — the token stays saved in this app until you tap "Log out".
